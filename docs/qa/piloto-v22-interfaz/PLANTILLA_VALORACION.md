# Plantilla de valoración de cada PDF · piloto V3

Una ficha por PDF adaptado. Para comparar, valora las dos adaptaciones del mismo material y perfil (planificador actual y V2.2) con la misma plantilla. Hay una versión en hoja de cálculo: [plantilla-valoracion.csv](plantilla-valoracion.csv), con una fila por PDF.

**Antes de compartir los resultados con ChatGPT u otra herramienta:**
- no incluyas datos de alumnado (los perfiles son ficticios A/B/C);
- no incluyas el texto de las reglas V2.2 ni de sus precedentes, que son privados;
- comprueba que la licencia del material permite compartir lo que pegues (columna «Derechos» del banco).

Compartir el informe de costes (`summary.json`) es seguro: no contiene contenido del material. `decisions.json` sí lo contiene.

## Ficha adaptada

Escala: **Cumple** / **Cumple con matices** / **No cumple** / **No aplica**. Indica siempre la evidencia (página y actividad). Los criterios siguen la hoja «Rúbrica y derechos» del banco de pilotos (Q01…).

| Criterio | Valoración | Evidencia (página, actividad) |
|---|---|---|
| Fidelidad: conserva objetivos, procesos y práctica; no cambia ítems | | |
| Perfil: no inventa necesidades ni confunde «no valorado» con «no necesita» | | |
| Apoyos: cada apoyo responde a una necesidad del perfil y a una demanda de la actividad | | |
| Control (perfil C): solo accesibilidad general, sin apoyos individuales | | |
| Respuestas: ningún ejemplo, figura o pista resuelve lo que se evalúa (prueba P1–P8) | | |
| Evaluación: los cambios en la forma de responder respetan la destreza evaluada | | |
| Visual: los esquemas esenciales siguen intactos | | |
| Práctica: no se reduce la cantidad ni la variedad | | |
| Edad: no infantiliza (sobre todo en ESO) | | |
| Idioma: mantiene el idioma original | | |
| Espacios de respuesta: suficientes y coherentes entre actividades comparables | | |
| Legibilidad e impresión (también en blanco y negro) | | |
